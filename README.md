# Rock Paper Scissors

A simple web game where you play against the computer. 

## 🎮 How to Play
1. Click Rock 👊🏼, Paper 🖐🏼, or Scissors ✌🏼.
2. The computer will instantly make its choice.
3. The scoreboard will track who wins each round.
4. Click *Reset Game* to clear the scores.

## ✨ Features
* Live score tracking.
* Responsive design.
* One-click reset.

## 🛠️ Tech Stack
* HTML, CSS, and Bootstrap 5
* JavaScript
